# Extensao-2

Esboço do Projeto - Atividade de Extensão II



1. Página inicial do site

- apresentação do projeto
- Objetivo: Ensinar informática básica e conceitos de lógica de programação
- Público-alvo
- Relação com a ODS 4 - Educação de Qualidade
- Botão "Começar curso"
- Botão "Entrar"

2. Cadastro

- Nome completo
- E-mail
- Senha
- Confirmação de senha
- Data de Nascimento
Ao concluir usuário é criado e direcionado para o login/curso.

(Salvo em banco de dados como usuários cadastrados - comprovação de aplicação do projeto)

3. Login

-E-mail
-Senha
-Botão Entrar
Ao concluir usuário é direcionado para Dashboard do aluno.

4. Dashboard:

- "Olá, Aluno! Seu curso está 35% concluído."

Vídeos de no máximo 3min:
- Módulo 1 - Conhecendo o computador
- Módulo 2 - Teclado e mouse
- Módulo 3 - Arquivos e pastas
- Módulo 4 - Internet
- Módulo 5 - E-mail
- Módulo 6 - Segurança digital
- Módulo 7 - Aplicativos básicos
- Avaliação final
Certificado

5. Aulas

- Personagens virtuais com as nossas características.
- Narração por IA. (com opção de deixar mudo)
- Texto curto explicativo
- Imagens/Animações
- Botões Anterior / Próximo
- Pequenos exercícios durante o curso (modo de ensino intuitivo)
- Marcação de aula concluída

6. Avaliação

- perguntas com questões de alternativas simples depois dos módulos.
- Marcação de acertos
